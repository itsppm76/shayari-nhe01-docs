01At a glance

Shayari NHE-01 is a governed AI companion with three conversational depths, a 20-axis emotion engine and a 14-component memory system. Since v135 it routes free and paid users through separate model pools under a hard $9.95 monthly spend ceiling per paid user.

02Architecture

One Apps Script project is the whole backend: the browser calls server functions, the server reads and writes one bound Google Sheet, and every model call leaves through a router that picks the free pool or the paid key by the user's plan.

04Turn workflow

Every message runs the same ordered pipeline: safety first, gates second, all independent network work in one parallel batch, then the reply model, then a server-side save before the reply returns.

askShayari() pipeline · v134 order, unchanged gate sequence

Response contract

Every turn returns JSON { reply, parts, meta }. meta carries activeClusterId, clusterMeta, isAdmin, username, cotTurnId, disengaged, crisis, mood, valence, arousal, imageId, imageError, and since v134 sessionStatus and lockStatus. Gate responses set planGate, limitReached (with resetsAtMs) or, since v135, budgetReached. Slash commands return plain text.

08Elysium X20 emotion engine

Shayari keeps a persistent 20-dimension emotional state per user that drifts with the conversation; it shapes tone silently and is never announced.

emotion.gs · barometer.gs · response meta feeds the client theme

The 20 dimensions and their baselines

AxisBaseAxisBaseAxisBaseAxisBase
warmth0.62empathy0.66curiosity0.55calmness0.62
excitement0.34playfulness0.32seriousness0.45confidence0.56
patience0.67tenderness0.58protectiveness0.40optimism0.60

Derived signals

valence   = mean(warmth, empathy, optimism, affection, tenderness) − (seriousness + urgency) / 10   → mapped to [0,1]
arousal   = mean(excitement, playfulness, urgency, curiosity)
stability = mean(calmness, patience, stability, resilience)
mood      = urgent | focused | bright | playful | gentle | calm | warm | concerned | grounded-warm

Style presets (urgent_support, focused_technical, playful_warm, calm_supportive, gentle_reassuring, grounded_warm) select the directive's voice. Signal categories map joy, sadness, anger, fear, love, philosophical, casual and urgency cues to small per-axis deltas (about ±0.03 to ±0.08). Users can read the state with /emotion.

v134 improvements. One EMOTIONS read per update instead of three; the turn count comes from the session already read; signal analysis runs once per turn instead of once per axis (identical results); the last mood is cached so Lightning's response meta needs no sheet read.

09Memory architecture: MEMBRANE 13 → MEMBRANE 14

MEMBRANE 14 adds a fourteenth component — the server-side Turn Ledger — and brings semantic recall live for the first time; the memory system is now durable, idempotent and filtered before decryption.

The repository documents the five core prompt layers as MemoryWeave. The thirteen MEMBRANE 13 components below are reconstructed from the v133 code; MEMBRANE 14 is that system plus the Turn Ledger, with the improvements marked.

Long-term memory scoring

score = importance × 10 + confidence × 5 + min(5, recallCount)

10Safety, privacy and governance

Safety modules run before product logic and can override it; privacy and authorization are enforced server-side, never trusted from the browser.

LIFELINE

Crisis detection runs before every gate. A keyword prefilter gates the classifier; engaged turns bypass lock, plan, limit and budget, consume no quota, and surface structured crisis resources.

SOVEREIGN · free will

Shayari can end a conversation on her judgment ([[DISENGAGE]]). A lock follows, with a 24-hour fallback clear and admin /unlock. Suspended during crisis turns.

COVENANT

Trust ledger 15–100, default 70. A disengagement costs 35; ordinary turns repair 0.4 plus 4 on a new day. Warmth modifier only — never a capability gate.

Privacy Shield

Opt-in stripping of emails, phone numbers and card-like digit runs before any model call — and, since v134, before storage and memory extraction.

Encryption at rest

AES-256-CBC + HMAC-SHA256, ENC1: prefix, key only in Script Properties. Honest scope: protects sheet access and leaks, not runtime processing.

Boundaries

No facial recognition, permanently. Identity and ownership claims accepted only from the verified admin. Global memory is admin-only — enforced server-side since v134.

Fixed in v134: the post-reply follow-up previously trusted isAdmin and forceGlobalMemory from the browser, so a crafted call could write GLOBAL_MEMORY. Admin rights now come from USERS and the server-armed turn record. open COVENANT's daily bonus compares a Date cell to text, so it currently applies every turn.

15Efficient product design and user experience

The product is designed so the user feels continuity and the operator controls cost: work the user can't see happens after the reply, and every limit explains itself.

Reply first, enrich later

Memory extraction, summaries, reactions and recall counters run in the follow-up after the reply is on screen.

Parallel by default

Independent calls share one fetchAll; the turn waits for the slowest, not the sum.

One read per concern

USERS, session, covenant and limit rows are read once and passed along; nothing authorization-relevant is cached across requests.

Degrade, never break

Every helper has a fallback: default cluster, null embedding, next vision model, cheaper paid level, free pool when the paid key is absent.

Limits that explain

Plan gates name the tier; limits show a countdown; the monthly budget message names the reset date.

Fewer client calls

Session and lock status ride on the reply, removing two round trips per turn.

Experience principles

  • Embodied, not announced: emotion and memory shape tone and content; mechanics are never narrated.
  • Continuity across modes: one thread, so switching depth never loses the conversation.
  • Honest disclosure: a fully disclosed non-human entity; encryption is described as at-rest, not end-to-end.
  • Care over engagement: BAROMETER check-ins are rare by design; outreach stops after three unanswered messages.
